## Architecture Reference

```
Request → AdmissionGateMiddleware (uses self.attribution: EntityAttributionEngine)
                                        ↕ shared instance
app.state.admission_attribution ← same EntityAttributionEngine
                                        ↕ read by
admission_enforcement.py router (_get_attribution() → EntityAttributionEngine)
```

The middleware increments `attribution.total_admitted` / `attribution.total_rejected`. The router reads these counters via the same shared object. This is the fix for the double-instantiation bug.
